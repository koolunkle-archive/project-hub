# DESIGN: Koolunkle's Hub

## 1. 무드 (Mood)

### 키워드: 에디토리얼 미니멀 (Editorial Minimal)

잡지 지면처럼 타이포그래피의 크기 대비로 정보 위계를 만들고, 장식 요소 없이 여백과 정렬만으로 신뢰감과 완성도를 전달하는 스타일입니다. 미니멀함(절제)과 프로페셔널함(신뢰감)을 함께 담습니다.

- 화려한 장식이나 트렌디한 효과(글래스모피즘, 뉴모피즘 등)를 지양합니다.
- "정돈된 개발자"라는 인상을 주는 것이 최우선 목표입니다.
- 채용 담당자가 빠르게 정보를 훑어볼 수 있도록, 스타일이 정보 습득을 방해하지 않습니다.

## 2. 컬러 (Color)

**60 · 30 · 10 법칙**을 기준으로 합니다.

| 구분 | 비율 | 색상명 | HEX | 용도 |
| --- | --- | --- | --- | --- |
| 배경색 (Base) | 60% | White | `#FFFFFF` | 페이지 배경, 카드 배경 |
| | | Light Gray | `#F5F5F5` | 섹션 구분 배경 |
| 보조색 (Secondary) | 30% | Dark Gray (Text) | `#1A1A1A` | 제목, 본문 주요 텍스트 |
| | | Mid Gray (Sub Text) | `#6B7280` | 설명글, 캡션, 날짜 |
| | | Border Gray | `#E5E5E5` | 카드 테두리, 구분선 |
| 포인트색 (Point) | 10% | Point Blue | `#2563EB` | 버튼, 링크, 활성 태그, 강조 요소 |
| | | Point Blue Hover | `#1D4ED8` | 호버 시 진한 블루 |

### 컬러 사용 원칙

- 포인트 컬러(블루) 외 다른 유채색 사용 금지
- 배경(60%)이 압도적 기준이 되어야 하며, 포인트 컬러는 전체 화면의 10%를 넘지 않도록 소량만 사용
- 그림자는 순수 블랙이 아닌 `rgba(0,0,0,0.05)~rgba(0,0,0,0.1)` 수준의 낮은 불투명도로 절제

## 3. 타이포그래피 (Typography)

### 폰트: 최대 2개 (제목용 1 + 본문용 1)

| 용도 | 폰트 | Weight | 비고 |
| --- | --- | --- | --- |
| 제목 (Heading) | Pretendard | Bold(700) / SemiBold(600) | 큰 크기로 과감하게 |
| 본문 (Body) | Pretendard | Regular(400) / Medium(500) | 담백하고 절제된 크기 |

> Pretendard 하나의 폰트 패밀리 안에서 굵기(weight)로 제목/본문을 구분합니다. 폰트 종류를 늘리지 않습니다.

### 크기 대비 원칙

어중간한 크기 차이가 가장 어색합니다. 제목과 본문의 크기 차이를 명확하게 벌립니다.

| 요소 | 권장 크기 (Desktop 기준) | Weight |
| --- | --- | --- |
| H1 (페이지 대표 타이틀, 예: 인트로 서비스명) | 48–64px | Bold |
| H2 (섹션 타이틀) | 32–40px | Bold/SemiBold |
| H3 (카드/항목 타이틀) | 20–24px | SemiBold |
| Body (본문) | 15–16px | Regular |
| Caption (날짜, 보조 텍스트) | 13–14px | Regular, Mid Gray |

> 20~28px 사이의 "어중간한" 크기는 제목도 본문도 아닌 애매한 인상을 주므로 지양합니다. 제목은 확실히 크게, 본문은 확실히 절제되게 갑니다.

## 4. 레이아웃 & 여백 (Layout & Spacing)

"무언가 더 채워야 할 것 같다"는 느낌이 들 때 오히려 멈추는 것을 기준으로 삼습니다.

- 섹션과 섹션 사이 간격을 넉넉하게 확보 (예: 데스크톱 기준 섹션 간 80–120px)
- 카드 내부 패딩을 넉넉하게 (예: 24–32px)
- 카드 간 그리드 간격(gap)도 촘촘하지 않게 확보
- 콘텐츠를 화면 끝까지 채우지 않고, 최대 너비(max-width)를 제한해 좌우 여백을 유지 (예: 본문 컨테이너 max-width 960–1120px)

## 5. 인터랙션 (Interaction)

채용 담당자가 여러 포트폴리오를 빠르게 훑어보는 맥락을 고려해, **미니멀하고 절제된 움직임**을 기본으로 합니다.

| 요소 | 인터랙션 | 세부 |
| --- | --- | --- |
| 카드 호버 | 그림자 진해짐 + 미세한 위로 이동 | translateY(-2px~-4px), shadow 강화 |
| 링크/버튼 호버 | 색상 전환 | Dark Gray → Point Blue, 또는 Point Blue → Point Blue Hover |
| 페이지/화면 전환 | 순간적 페이드인 | opacity 0→1, 슬라이드/복잡한 트랜지션 지양 |
| 트랜지션 속도 | 150–250ms | 빠르고 즉각적인 반응감 유지 |

- 큰 움직임(바운싱, 회전, 과도한 슬라이드) 없이 opacity/shadow/color 위주의 미세한 피드백만 사용합니다.
- 로딩이나 전환이 사용자의 정보 습득 속도를 늦추지 않도록 합니다.

### 필수 적용 인터랙션

| 요소 | 인터랙션 | 세부 |
| --- | --- | --- |
| 스크롤 리빌 (Scroll Reveal) | 스크롤에 따라 섹션/카드가 순차적으로 나타남 | opacity 0→1 + 8~16px 미세한 이동, `IntersectionObserver` 또는 GSAP `ScrollTrigger` |
| 스태거드 애니메이션 (Staggered Entrance) | 리스트/그리드 카드가 동시에 아닌 순차 등장 | 카드 간 50–80ms 간격 딜레이, GSAP `stagger` 또는 CSS `animation-delay` |

> 두 인터랙션 모두 "화려함"이 아닌 "정보 탐색을 돕는 리듬감"이 목적이므로, 이동 거리와 속도는 기본 인터랙션 표(카드 호버, 트랜지션 속도 등)의 절제 기준을 그대로 따릅니다.

### 선택적 적용 인터랙션 (필요 시에만, 페이지당 1곳 이내 권장)

| 요소 | 인터랙션 | 적용 위치 예시 | 비고 |
| --- | --- | --- | --- |
| 스크롤 프로그레스 인디케이터 | 상단에 얇은 Point Blue 라인으로 읽은 비율 표시 | 프로젝트 상세 페이지 | 장식이 아닌 정보성 요소로 예외 허용 |
| 커서 반응 그림자 (Spotlight) | 카드 위 마우스 위치에 따라 그림자 방향이 은은하게 이동 | 프로젝트 리스트 카드 | 반드시 은은하게, 과하면 산만해지므로 신중히 적용 |
| 텍스트 리빌 (Text Reveal) | 제목이 단어/글자 단위로 페이드인 | 인트로 페이지 H1 1곳 | 페이지당 1회 이내로 제한, 남발 금지 |

### 지양하는 인터랙션

아래 항목들은 "에디토리얼 미니멀" 무드 및 금지사항(화려한 애니메이션 금지)과 직접 충돌하므로 적용하지 않습니다.

- 패럴랙스 스크롤 (배경/전경 다른 속도) — 정보 탐색에 산만함을 줄 수 있음
- 커스텀 커서 (원형 블롭 등) — 프로페셔널 톤과 결이 다름
- 스크롤 하이재킹 (스냅 스크롤, 풀페이지 전환) — 정보 탐색 속도를 늦춤
- 3D 틸트/카드 회전 효과 — 화려한 애니메이션 금지 원칙과 충돌

## 6. 금지사항 (Design Don'ts)

- **포인트 컬러(블루) 외 다른 유채색 사용 금지** — 배경/텍스트는 그레이스케일, 강조는 오직 블루 하나로만
- **과도한 그라데이션/그림자 효과 금지** — 그림자는 낮은 불투명도로 절제, 그라데이션 배경 지양
- **화려한 애니메이션(바운싱, 회전 등) 금지** — opacity/shadow/color 중심의 미세한 피드백만 허용
- **이모지/일러스트 남발 사용 금지** — 텍스트와 여백, 타이포그래피로 정보를 전달
- **폰트 종류 혼용 금지** — Pretendard 최대 2가지 용도(제목/본문)로만 사용, 다른 폰트 패밀리 추가 금지
- **어중간한 크기 대비 금지** — 제목과 본문 사이에 애매한 중간 크기 요소를 만들지 않음
- **여백을 아끼지 않기** — 콘텐츠로 화면을 빽빽하게 채우지 않음
