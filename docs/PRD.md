## 2. 페이지 구성

```text
1. 인트로 페이지 (Intro)
   └─ ENTER 버튼 클릭
2. 프로젝트 리스트 페이지 (Projects)
   └─ 카드 클릭
3. 프로젝트 상세 페이지 (Project Detail)

+ About 페이지 (자기소개)
```

전체 사이트는 위 4개 화면(3개 플로우 + About)으로 구성됩니다. About 페이지는 별도 진입점(예: 상단 네비게이션)을 통해 어디서든 접근 가능하도록 합니다.

### 3.3 프로젝트 상세 페이지

카드 클릭 시 진입하는 상세 화면으로, 아래 항목들로 구성합니다.

| 항목 | 포함 여부 | 비고 |
| --- | --- | --- |
| 기본 정보 (설명, 기술스택, 기간, 카테고리) | ✅ 필수 | 리스트 카드 정보 확장 |
| 담당 역할 및 주요 기여 내용 | ✅ 포함 | 기록된 내용 존재, 바로 반영 가능 |
| 스크린샷/이미지 갤러리 | ⚠️ 선택적 | **커리어 프로젝트는 보안상 제외** (코드/이미지 노출 불가). 개인 프로젝트는 있는 경우에만 노출 |
| 트러블슈팅/기술적 도전 사례 | ⚠️ 필드만 준비 | 데이터(`challenges`, `retrospective`)가 있는 프로젝트에만 섹션 노출 |
| 배운점/회고 | ⚠️ 필드만 준비 | 데이터(`challenges`, `retrospective`)가 있는 프로젝트에만 섹션 노출 |
| 성과/지표 | ❌ 제외 | 개인 프로젝트/MVP 단계로 노출할 지표 없음 |
| GitHub 링크 | ✅ 포함 | 공개 가능한 프로젝트에 한해 |

> **주의**: "트러블슈팅/기술적 도전 사례"와 "배운점/회고" 필드는 UI/데이터 구조상 미리 만들어두되, 콘텐츠가 없는 프로젝트는 해당 섹션을 노출하지 않거나 "준비 중" 처리합니다.
